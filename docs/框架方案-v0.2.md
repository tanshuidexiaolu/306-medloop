## 1. 三分钟读完

**一句话**：把 306 的 203 个考点做成一张会自己衰减的"掌握度地图"，按你定的**复习截止日**倒推每天该练什么，并用 306 / 执业医师 / USMLE / 日本医师**四种风格**反复考同一个考点，练完自动算出你当前能考多少分。

**四个关键设计选择**

| 选择 | 我的建议 | 理由 | 代价 |
|---|---|---|---|
| 个性化靠什么 | 掌握度 + 记忆稳定性**双参数** | 对错率分不清"不会"和"忘了" | 连续用 3~5 天才收敛 |
| 每天练什么 | 按**截止日倒推**生成计划 | 有截止日才有节奏；改日期能立刻看到"来不来得及" | 需要你接受"截止日过紧就提示减负" |
| 时间轴锚点 | **复习截止日**（可自由调，含日期与时刻） | 你的节奏你定，不绑死考试日 | 没有"考试倒计时"的紧迫感，需要自己定合理日期 |
| 题库结构 | 306 主线 + 三种外域风格的**变式题**，同一考点打通 | 只刷 306 表述容易"背题面"，变式才能验出是否真懂 | 命题与审核工作量增加约 30% |

**需求已确认**：四项功能全要（题海+错题本+遗忘曲线 / 每日计划+督学 / 模考+分数预测 / 图谱+薄弱诊断）；题库由我按考纲与教材生成、你审核。

**待你拍板**：§13 共 9 项，最影响 P1 开工的是：复习截止日、每日时长、六科自评、四种题的题量分配。

## 2. 产品定义

### 2.1 三类使用场景

| 场景 | 时长 | 设计支撑 |
|---|---|---|
| 碎片时间 | 5–15 min | 手机可用、单次 5~15 题、随时中断不丢进度 |
| 每日复习 | 1–2.5 h | 截止日倒推的每日任务量、进度条、连续天数 |
| 周度检验 | 2–3 h | 306 全真/迷你模考、结构化报告、与上次对比 |

### 2.2 它解决什么

1. **不知道练什么** → 每天打开就是排好序的清单，附"为什么安排这个"和"今天必须完成多少"
2. **刷完就忘** → 每个考点记记忆稳定性，到期自动回流
3. **不知道自己什么水平** → 每答一题更新掌握度，随时给 300 分制预测分与区间
4. **错题反复错** → 错题本 + 关联考点 + 同考点变式重做
5. **只会 306 的题面** → 用执业医师的病例串题、USMLE 的决策链、日医的否定提问换角度考同一考点
6. **不知道自己来不来得及** → 截止日可行性评估 + 预计完成日期

### 2.3 不做

- ❌ 社交、排名、自习室、打卡朋友圈
- ❌ 政治/英语；不做 306 以外科目的完整课程
- ❌ 押题、预测题、内部消息
- ❌ 不替代教材和视频课——定位是"练"
- ❌ 不复制、不改写任何真题原文（含 USMLE / 日医 / 执业医师真题），只做同考点仿真题

### 2.4 四类题源的定位（本版新增，核心）

| 题源 | 原生结构 | 中文适配方式 | 在系统中的角色 | 默认题量 |
|---|---|---|---|---|
| **306 统考** | A1/A2/B/X，165 题 300 分 | 原文即中文 | **主线**：计划主体、全真模考、分数预测 | 410 |
| **执业医师（临床类别）** | A1/A2/**A3/A4 病例串题**/B1，4–5 选项 | 原文即中文 | 练"同一病例多问"的病程推进思维；串题能力对 306 的 A2 有帮助 | 40 |
| **USMLE（Step 1 / Step 2 CK 风格）** | 5 选项单选；长病历（年龄性别+主诉+病史+查体+化验+影像）；问 most likely diagnosis / next best step / mechanism | 译为中文，术语首次出现括注英文（如"急性肾损伤（AKI）"） | 练长题干信息提取与**临床决策链**；Step 1 偏机制，Step 2 CK 偏处置 | 40 |
| **日本医师国家试验** | 5 选 1（A 型）；"2 つ選べ"选 2 项；"誤っているのはどれか"否定提问 | 译为中文，保留结构特征并显式标注【选 2 项】【选出错误项】 | 练**审题精度**与抗陷阱（否定提问、漏选） | 40 |

**两条使用规则**（避免污染 306 预测分）：

- **同考点变式**：映射到 306 大纲考点，参与掌握度更新 → 用于判断"你是真懂还是只背了题面"
- **拓展知识**（`beyond: true`，306 大纲之外但相关的内容）：单独记进度，**不计入掌握度、不计入 306 预测分**

## 4. 核心流程

**首次进入（约 25 分钟）**

```
设置复习截止时间（日期+时刻，可先给个大概）
        ↓ 实时显示"按此截止日，每天需完成 N 题，可行性：宽松/紧张/不可行"
设置每日可用时长、每周学习天数、六科基础自评
        ↓
能力诊断卷（24 题，6 科各 4 题，含 1 道变式题）
        ↓
生成初始掌握度画像 → 生成第一份 7 天计划 + 截止前完成预测
```

**每日循环**

```
打开今日页 → 看到"今日必须完成 X 题"与 3 个计划块
   ↓
答题（306 主线为主，穿插变式题）
   ↓ 即时判定，更新掌握度 + 记忆稳定性 + 题源统计
会话结束报告（正确率 / 用时 / 涉及考点 / 错题）
   ↓
夜间重算：明天哪些考点到期、按当前速度预计哪天完成
```

**截止日调参闭环（本版新增，核心交互）**

```
任何时候改截止日
   ↓ 立即重算：剩余工作量 W → 每日目标 w̄ → 可行性 F = 容量 c / w̄
   ├ F ≥ 1.3  宽松：提示"可增加变式题或提前完成"
   ├ 1.0–1.3  紧张：保持，不建议再加量
   └ F < 1.0  不可行：给三条解法
        ① 延后截止日（自动算出最早可行日期）
        ② 增加每日时长
        ③ 降低达标线（掌握度 0.75 → 0.65）
```

**多风格训练流程**

```
正常计划（306 主线）
   ↓ 某考点掌握度 ≥0.7 且保持率达标
系统在训练块里插入 1 道该考点的"变式题"（执业/USMLE/日医，轮换）
   ↓ 答错 → 掌握的判定回退，"只记住题面"被识别
   ↓ 答对 → 风格迁移度上升，该考点才算真达标
```

## 6. 数据模型

### 6.1 考点树（不变）

```
学科 subject (6) → 章 chapter (48) → 考点 kp (203)
kpId = "学科::章::考点"，例：internal::循环系统疾病::心力衰竭
```

考纲分值与题量（2026 版，系统内可改）：内科 33% / 外科 23% / 生理 14% / 生化 12% / 病理 12% / 人文 6%；A型 1–40（1.5分）、41–115（2分），B型 116–135（1.5分），X型 136–165（2分），共 165 题 300 分。

### 6.2 题目 schema（本版扩 5 个字段）

```js
{
  id: "int-usm-001",
  subject: "internal",              // 306 六科之一（变式题也挂到 306 考点上）
  chapter: "循环系统疾病",
  kp: "冠心病与急性冠脉综合征",
  style: "usmle",                   // ★新：cn306 | cn_practice | usmle | jp
  type: "A2",                       // A1 | A2 | B | X | X2（选2项）
  ask: "normal",                    // ★新：normal | negative（"错误的是"）
  chooseN: 1,                       // ★新：需选几项（日医 X2 = 2）
  caseId: "CASE-INT-01",            // ★新：串题组（共用题干），无则省略
  caseOrder: 1,                     // ★新：组内顺序
  beyond: false,                    // ★新：true = 306 大纲外拓展知识，不计入预测分
  difficulty: 0.7,
  stem: "该患者最可能的诊断是",
  caseText: "男，58 岁，持续性胸痛 2 小时……",   // 串题材料
  options: ["急性心包炎", "急性下壁心肌梗死", "不稳定型心绞痛", "主动脉夹层", "肺栓塞"],
  answer: [1],
  explain: "……",                    // ≥60 字，逐项说明错因
  tip: "下壁 = Ⅱ/Ⅲ/aVF",
  source: "自编·USMLE Step2 风格·人卫《内科学》第10版 P264"
}
```

## 7. 算法设计

### 7.1 掌握度（不变）

```
答对： m ← m + 0.22·(1−m)·(0.7+0.6d)
答错： m ← m − 0.30·m·(0.5+0.8(1−d))
```

### 7.2 记忆保持率（不变）

```
R = exp(−Δt / S)，答对 S ← S·(1.7+0.35d)，答错 S ← S·0.5
R < 0.78 → 进入待复习队列
```

### 7.3 出题优先级（加风格维度）

```
优先级 = [0.45(1−m) + 0.35(1−R) + 0.15·错率 + 0.05·久未练] × (0.55+1.5·学科权重)
再叠加：
  · 难度匹配：预测正确率 p≈0.65 优先（p = sigmoid((m−d)·7+0.35)）
  · 5 天内做过的题降权
  · 风格多样性：该考点近 30 天只练过 306 → 变式题权重 ×1.4
  · 迁移缺口：风格迁移度 <0.7 的考点 → 非 306 变式权重 ×1.6
```

### 7.4 截止日驱动的每日计划（本版核心，替代"按考试倒推"）

```
剩余自然日    N = max(1, deadline − today)
有效学习日    D = max(1, N × (每周学习天数 / 7))
剩余工作量    W = Σ_kp w(kp)
    w = 1.00  未学习
      + 0.70  薄弱（m < 0.5）
      + 0.35  待复习 / 巩固中
      + 0.00  已掌握（m ≥ 达标线 且 R 达标）
每日目标工作量 w̄ = W / D
每日容量       c = dailyMinutes / 平均每题分钟（约 1.6 min/题）
今日必须完成   题量 = ceil(min(w̄, c) × 平均每题工作量系数)
```

计划仍切三块，但**比例随截止可行性动态调整**：

| 块 | 正常 | 截止紧张时 | 目的 |
|---|---|---|---|
| 遗忘曲线复习 | 26% | 降到 20%（保底） | 防遗忘，性价比最高，不能被挤掉 |
| 短板突破 | 40% | 升到 50% | 结构性缺口优先补 |
| 跨章综合 + 变式 | 34% | 降到 30% | 保住临床思维，变式题也在此块 |

### 7.5 可行性评估与预计完成日（本版新增）

```
可行性 F = c / w̄
  F ≥ 1.3   宽松   → 可加变式题 / 提前完成
  1.0 ≤ F < 1.3  紧张 → 保持，不再加量
  F < 1.0   不可行 → 三条解法：
     ① 延后截止日：最早可行日 = today + ceil(W / (c·ρ))
     ② 提高每日时长：需要 minutes = w̄ × 1.6
     ③ 降低达标线：masterLine 0.75 → 0.65（会少覆盖约 15~20% 考点）

实际速度  v = 近 7 天平均每日完成工作量（首周用计划值）
预计完成日 = today + W / max(v, 0.1)
进度差     = 当前已完成工作量比例 − 应达比例（按时间线性）
```

### 7.6 分数预测（本版加迁移修正）

```
学科预测分 = 学科满分 × (0.16 + 0.84 × 掌握度) × 覆盖率修正
总分 = Σ 学科预测分 ± 15
迁移修正：若某科非 306 变式正确率显著低于 306 正确率，
         该科预测分 × clamp(0.85, 1.0, 变式正确率/306正确率)
```

**边界**：`beyond: true` 的拓展题不计入掌握度、不计入预测分，只记拓展进度。

### 7.7 风格迁移度（本版新增指标）

```
迁移度 = 非306风格正确率 ÷ 306风格正确率     （该考点累计样本 ≥3 才显示）
  ≥ 0.9   真理解
  0.7~0.9 基本掌握，表述依赖略高
  < 0.7   ⚠ 可能只记住了 306 的题面 → 推荐变式专项
```

用途：知识图谱考点行显示；学习报告里给出"迁移度最低的 10 个考点"清单；也是"换风格再考"按钮的触发依据。

### 7.8 冷启动与边界

| 情况 | 处理 |
|---|---|
| 全新用户 | 六科自评初始化先验 → 诊断卷（含 1 道变式）校正 |
| 未设截止日 | 默认"今天 + 60 天"，并在今日页提示去设置 |
| 截止日已过 | 提示"截止日已过"，给"顺延 7 天 / 重设"两个按钮，不锁死功能 |
| 某考点无题 | 计划里跳过并提示"补齐题库后自动覆盖" |
| 题库不足组不出卷 | 明确报缺口（缺几题、缺哪个题型/题源），不重复凑题 |
| 变式题样本不足 | 迁移度显示"—"，不做判断 |
| 长期不学 | 全部 R 衰减，回来首日生成"补救复习"重块 |

### 7.9 参数表（设置 → 高级可调）

| 参数 | 默认 | 含义 |
|---|---|---|
| 答对增幅 / 答错降幅 | 0.22 / 0.30 | 掌握度敏感度 |
| 稳定性增益 | 1.70 | 每次答对记忆稳定性倍数 |
| 复习阈值 | 0.78 | 低于此值进复习队列 |
| 达标线 masterLine | 0.75 | 算"已掌握"的门槛，截止紧张时可降至 0.65 |
| 变式题占比 | 15% | 训练块里非 306 题的比例（P4 可调 0~40%） |
| 目标覆盖率 | 85% | 截止前希望覆盖的考点比例 |

## 8. 题库生产方案

### 8.1 规模（410 → 530）

**A. 306 主线 410 题**（按考频分层，同 v0.1）

| 档位 | 考点数 | 每题量 | 小计 |
|---|---|---|---|
| 高频 | ~60 | 3 | 180 |
| 中频 | ~90 | 2 | 180 |
| 低频 | ~50 | 1 | 50 |

题型配比对齐考纲：A1 24% / A2 45% / B 12% / X 18%。

**B. 拓展题库 120 题**（覆盖高频 60 个考点 + 少量 beyond）

| 题源 | 题量 | 覆盖策略 |
|---|---|---|
| 执业医师风格 | 40 | 其中 8 组 A3/A4 串题（每组 2~3 问） |
| USMLE 风格 | 40 | Step1 机制 15 / Step2 CK 决策 25 |
| 日本医师风格 | 40 | 5 选 1 二十五题 / 选 2 项 十题 / 否定提问 五题 |

要求：**每个高频考点至少 1 道非 306 变式**，用于迁移度计算。

### 8.2 四风格命题规范

| 维度 | 306 | 执业医师 | USMLE | 日本医师 |
|---|---|---|---|---|
| 题干长度 | 中 | 中 | **长**（患者+病史+查体+化验+影像） | 中短 |
| 提问方式 | 最可能诊断/首选检查/首选治疗 | 同上，病例串题递进 | most likely / **next best step** / mechanism | どれか → "下列哪项"，含否定与选 2 项 |
| 选项数 | 4~5 | 4~5 | **5** | **5** |
| 典型陷阱 | 相似病鉴别 | 检查/治疗的**优先级**错误 | 先稳定还是先确诊；过度检查 | 漏看"错误""2 项" |
| 中文处理 | 原文 | 原文 | 译为中文 + 英文术语括注 | 译为中文 + 结构标注 |

### 8.3 字段与审核表

技术字段见 §6.2。审核表额外两列：**教材依据**（如"人卫《内科学》第 10 版 P264"）、**命题意图**（考哪个鉴别点）。

### 8.4 六条质量红线

1. 只写教材与考纲明确结论；不写更新快的指南数值（剂量、截断值除非教材原文给出）
2. 选项互斥、答案唯一；X 型 2~4 项、选 2 项恰好 2 项
3. 解析逐项说明错因，不能只写"答案是 B"
4. **不复制任何真题原文**（含 USMLE / 日医 / 执业医师真题），只做同考点仿真题
5. 病例信息完整：主诉 + 关键体征/检查 + 明确问题
6. **翻译不得改变医学事实**；术语统一，英文缩写首次出现括注

### 8.5 审核流程

```
① 我生成 40~50 题/批 → 跑自动校验（格式/考点/答案/串题组完整性）
② 导出《题库审核表.xlsx》：编号·题源·学科·章节·考点·题干·选项·答案·解析·教材依据·审核结论
③ 你审：通过 ✅ / 改后通过 ✏️（写意见） / 废弃 ❌
④ 我按意见修订 → 二次校验 → 入库 → 更新覆盖率
```

**工作量**：306 主线 8 批 + 拓展 3 批 = 11 批，每批 40–60 分钟；可分 3–4 周并行于你的日常复习。

### 8.6 版权与准确性边界

- 四类题目均为**仿真题**，不复制、不改写真题原文；真题导入由你负责版权
- USMLE / 日本医师内容的**中文表述以人卫版教材口径为最终依据**，不引用境外指南原文
- 产出为学习材料，不构成医疗建议

## 9. 技术选型与取舍

**选：纯静态（HTML + CSS + 原生 JS，无构建、无依赖、localStorage）**

理由：零安装、你随时能打开看、隐私不出本机、整个文件夹拷走即用。不选 React/Vite：框架阶段多一层构建是负担；`engine.js` 不依赖任何框架，日后要迁多端可原样复用。

**已知局限与对策**

| 局限 | 影响 | 对策 |
|---|---|---|
| 不能多设备同步 | 手机/电脑数据分离 | 导出/导入 JSON；P5 再做云同步 |
| 浏览器清数据会丢 | 学习记录清零 | 每周导出提醒；P1 内置备份 |
| `file://` 下 localStorage 可能被禁 | 无法保存 | 已内置降级：内存模式 + 明确提示 |
| 165 题全真模考需 ≥200 题 306 题 | 题库不足开不了 | 组卷报缺口；P3 补齐 |
| 多风格翻译质量 | 术语不一致、语义漂移 | 你的审核为最终关口；术语表统一 |
| 拓展题可能拉偏复习重心 | 时间被非考点内容占用 | 变式占比默认 15%，可关；beyond 不计预测分 |
